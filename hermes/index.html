Hermes personal dashboard

This is an information page for a private, single-user assistant and dashboard operated by the site owner. It is separate from EdgeRent's student-rental services; this page does not provide access to the private dashboard.

What the connection does

With the account owner's permission, the assistant can read, search, send, and organize Gmail messages when asked, and read or manage Google Calendar events. The local dashboard displays calendar events on the owner's home network. Google OAuth authorization can be revoked at any time from the Google Account permissions page.

See the privacy policy for how Google account data is handled.
